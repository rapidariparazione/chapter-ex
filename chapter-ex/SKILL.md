# chapter-ex · 概念理解版阅读页

读者不是在备考，是想真正弄懂这一章：每个概念是什么、为什么这样、和别的概念怎么连。
只交一样东西：`第N章.html` 阅读页。单个文件，双击就能在浏览器里打开。可以划线、点选做题、点术语看解释、调字号、接着上次读。
划线和做题记录存在读者自己的浏览器里（localStorage），换浏览器或清缓存就没了。
如果在 Claude 的 artifact 里发布，会改用 artifact 自带的存储。

做的过程中会在同一个文件夹留下两个工作文件，不用交：`第N章.md`（笔记源文件）、`账本-第N章.md`（事实账本，每条改写都对得回原文）。

脚本都在本技能的 `scripts/` 目录，下面记作 `$S`。

## 需要的工具

- Python 3.8 以上。
- 从 PDF 抽文字，二选一：pypdf（`pip install pypdf`，Windows 推荐这个），或 poppler 的 `pdftotext`。
  两样都有时优先用 pdftotext。两样都没有，脚本会提示先装 pypdf。
- （可选）poppler 的 `pdftoppm`：把书里有图表的页渲染成图片来看。没有就跳过。
- （可选）Chrome、Chromium 或 Edge：只用来给插图截图（第三道检查）。
  找不到时设环境变量 `CHROME=浏览器可执行文件路径`。没有就跳过截图，直接用浏览器打开 HTML 逐张看图。

## 命令怎么写

- 下面的命令写的是 `python3`。**Windows 上换成 `python`**（或 `py -3`）。
- `$S` 指本技能 `scripts` 文件夹的完整路径，运行时直接替换成真实路径。
- 文件名、路径里有空格或中文时，加双引号。

## 流程

1. **拿原文。** `python3 $S/pdftext.py 原书.pdf 原文.txt`。整本书的 PDF 可以加起止页：`python3 $S/pdftext.py 原书.pdf 原文.txt 45 78`。
   书里有图表的页，有 pdftoppm 就用 `pdftoppm -f A -l B -r 110 -png 原书.pdf pg` 渲染出来看；没有就请用户截图，或跳过。
2. **定读法和图的风格**，写在 md 页顶（见「页顶」一节）。
3. **建事实账本**，再写 md。写法看 `references/notes-guide.md`，md 语法看 `references/md-format.md`。
4. **过六道检查**，一道不过就改，改完再跑。
5. **转 HTML**：`python3 $S/md2art.py 第N章.md "<书名> · 第 N 章 · 概念理解版" "<页面标题>" 第N章.html`
   转完在浏览器里打开翻一遍。md2art 只认 `references/md-format.md` 里的写法，别的写法会被当成普通段落，不报错。
6. **交回**：HTML 文件的路径、六道检查的数字、哪几张图是示意、哪样没验过（比如手机宽度）。

## 写 md 时守的规矩

1. 每句不超过 25 个汉字（`**标签：**` 不算）。落笔就按短句写，不靠事后切。
2. 不用破折号「——」。
3. 书中例子只写原文里有的。凭印象写的，先回原文搜一遍。
4. 作者的推测要标「这是作者的推测，书里没给数据」。
5. **7 道选择题**，每题 A 到 D 四个选项。
   题干一行 `**Q1：…？**`，下面四行 `- A. …` 到 `- D. …`，再接 `<details>` 折叠块，第一句写「答案：X。」再写理由。
   对的那项在 A 到 D 之间轮换。错的三项取原文里的近邻说法，要像真的。
   出完自己过一遍：哪道题不读正文也能排除两个选项，就重写那两个错项。
6. 原书跟常识对不上（人名、年代、地名），照原书写，紧跟一句「书里写的是 X，实际是 Y。」
7. 正文最前面放 `## 关键词：作者在这篇里指什么`。列 5 到 10 个词。
   每条写成 `1. **中文（英文）**：意思。不是……。`。页面靠 `**中文（英文）**` 认术语，正文里第一次出现处点了就弹出解释。
8. 关键词之后放 `## 先读这一屏`：一行 `**一句话：** …` 说这一章最后讲了什么，下面一张总图。
   总图里每个框用 `<a href="#s1-1">…</a>` 包住，点了跳到那一节。页面自带「回到刚才」按钮。
   总图下面放折叠块 `<summary>作者的问题答上了没</summary>`：先写主问题，再写 2 到 4 个次要问题，
   每个标「答上了 / 答了一半 / 没答」，写在哪一节、差在哪。只按原文判。
9. 每个小节标题写成 `### 1-1 标题（English Title）`，下一行 `**页码：** 第 A 到 B 页。`（用 PDF 页码）。
10. 讲概念先用一句不带术语的大白话，再配一个读者生活里的例子，最后才给原文的名字。
    例子取刚工作的年轻人不用查就懂的事：上班、租房、领工资、开会、做饭、看病、寄快递、坐地铁。
    书中例子照常保留，但不能只用读者陌生的外国背景例子。
    原文的专业词，正文里换成大白话的叫法。原名只在关键词那一节出现一次。
11. 每节挑一个比方，主线之后写一行 `**本节比方：** A 比作 B。`
    每条理由、每个步骤后面，跟一句用本节比方说的话，句首加 🔸。
    比方要跟原文一一对得上：同一节里对应关系不换，不替作者编理由。管不到的地方明写「比方到这里不管用」。
12. 有英文原文的书，每节中文讲完，接一个折叠块 `<summary>原文这一段</summary>` 放整段原文，批注写在原文下面。
13. 文中有两三种做法或说法时，放一组并排卡（```html 块里用 `<div class="cmp">`），每张三行：是什么、好处、代价。
    原文没推荐的，不许写成「该这样做」。
14. 每节末尾放 `#### 推论回放`：把作者这一节怎么推到结论，按 1、2、3 步再走一遍，最后一步写「所以：…」。
    全篇最后放 `## 全卷推论回放`，把各节串成一条线。
15. 7 道选择题后面放折叠块 `<summary>作者哪里能挑错</summary>`，四样各一句：
    知识不够、说错了（给出处）、推不出（指明哪一步断了）、没讲完。每样标「这是我的判断」，找不到就写「没找到」。
16. 每句不是原文的话标清来路：原文用 📖；自己算的数后面写「（推算：怎么算的）」；
    从书里图表读出的数标「（读图）」；示意图的图注写「示意，不是数据」；自己的理解标「这是我的判断」。
17. 数字和关键判断后面加角标 `[^47|📖 "原句"]`，47 是 PDF 页码，点开看原句和页码。
18. 正文里放两处「先猜再看」：挑最反直觉的两个数或结论，放在讲它之前。写法同第 5 条，题号写 `**猜1：…？**`。
19. 每章 1 到 2 个实验台：挑最难懂的概念，做成能动手的小机器（拖、点、切档、分步都行），写在 ```html 块里。
    只用原文给过的数，原文没给的图注写「示意，不是数据」。旁边一句写清动哪里、看什么变。按钮至少 44 像素高。

## 页顶

md 第一行 `# 标题`，接着几行 `> ` 开头的简介。其中两行有特殊用途：

- `> 读法：X`。X 选一个：
  概念探索（教材、原理）：总图画概念之间的关系，实验台做概念。
  查读（手册、技巧书）：每节首行写「什么时候来查这一节」，总图画整个流程。
  数据钻取（报告）：一句话写结论的数，正文按全局、分部、原因、风险往下走。
  论证拆解（论文、论说文）：总图画成「问题 → 方法 → 证据 → 结论」。
  叙事（历史、传记）：总图画成时间线，正文按时间推进。
- `> 风格：X`，只改插图配色。X 选一个：手绘笔记、杂志、蓝图、铜版。不写就是默认翡翠绿。

## 插图

- 每章 3 到 6 张，画结构、对比、流程，不画装饰。图放在每节开头。
- 动笔前先写一句美术方向：要人一眼看出什么。
- 写在 md 里的 ```svg 代码块，下一行写图注 `*这张图回答：…？*` 或 `*图：…*`。
- 颜色只用 `scripts/pic.css` 里的 class：t s a b sm xs soft grp box box2 ln lna arw stk stka fa fsoft fgrp dash。不写死颜色，深色模式才跟得上。
- 弧线和曲线不用 `lna`、`stka`（它们没有 fill:none，会被填成色块），用 `arw` 或 `stk`。
- 书里有关键图表的，挑一张重画成网页图，点数据点显示读图值和页码。
- 需要分步出现或滑动的动态图：先把 `$S/dyn.html` 原样贴进 md（一章只贴一次），
  图写成 ```html 块：`<figure class="pic" data-dyn data-say="第0步|第1步|…">`，分步元素加 `data-s="k"`，
  要滑的包进 `<g class="mv" data-s="k" style="--to:translate(40px,0)">`。

## 六道检查（缺一道不交）

1. **引文**：`python3 $S/quotecheck.py 第N章.md 原文.txt`，要报「N / N」。有 MISS 就改。
2. **句长**：`python3 $S/chk.py 第N章.md`，第一行是超长句数，要为 0。超长句逐句手改。
   `python3 $S/autosplit.py 第N章.md` 只用来列出哪几句超长，不要加第二个参数让它自动改，它会切出半截句。
3. **图**：`python3 $S/figshot.py 第N章.html` 把所有插图截成一张 png，打开看原尺寸：文字压线、被裁、标签重叠都要改。没有浏览器可调用时，改成在浏览器里打开 HTML 逐张看。
4. **页码**：`python3 $S/pagecheck.py 第N章.md 原书.pdf`，要报「N / N」。它拿每节第一句 📖 引文去那一节标的页里找。
5. **改写核对**：写 md 之前先建 `账本-第N章.md`，一条一行：
   `F01 · 第 47 页 · 📖 "原句" · 改写：中文那句`。每节的数字和核心判断都要进。
   跑 `python3 $S/quotecheck.py 账本-第N章.md 原文.txt`，要报「N / N」。
   再逐条对 9 类错：单位换算、主宾颠倒、丢了例外或条件、说过头、顺序反了、细节过多、数数或读图错、两个近义概念混成一个、自己的评论没标。改过的在行末写「改：哪一类」。
6. **难点抽查**：从账本里挑 12 条最容易错的，回 PDF 那一页逐条对，在回复里列出：编号、页码、对上了还是改了什么。

## 在 Claude 的 artifact 里发布（可选）

在有 Artifact 工具的环境（如 Claude Code）里，可以把 HTML 发布成 artifact，capabilities 给 `{"db": {}}`。
页面会自动改用 artifact 的 db：划线存进 highlights 集合，做题存进 quiz 集合，换设备也在。
没有这个工具或拿不准的环境，就交 HTML 文件，读者用浏览器打开。
