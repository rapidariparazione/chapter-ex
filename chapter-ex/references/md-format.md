# md2art.py 认得的 Markdown 写法

`scripts/md2art.py` 只认下面这些写法。别的写法会被当成普通段落，不报错，所以转完要在浏览器里翻一遍。

## 页顶

```
# 📝 书名 · 第 3 章 · 章标题
> 一两句简介，说这一章讲什么。
> 读法：概念探索
> 风格：手绘笔记
```

第一行是页面大标题（`📝 ` 会被去掉）。第一个 `## ` 之前、以 `> ` 开头的行都进页顶简介。

## 大节和小节

- `## 关键词：作者在这篇里指什么`：大节标题。写成 `## 正文` 的不显示标题。
- `### 1-1 标题（English Title）`：编号小节，自动进目录，锚点是 `#s1-1`。括号里的英文显示成副标题。
- `### 其他标题`：不编号的卡片，不进目录。
- `#### 推论回放`：卡片里的小标签。

## 原文引文

```
> 📖 "English sentence exactly as in the source."
> **译：** 中文译文。
```

第二行可省。引号必须是直的双引号 `"`，quotecheck 和 pagecheck 靠它找原句。

## 角标

`[^47|📖 "原句"]` 变成右上角的 `p.47` 按钮，点开看原句。

## 图

````
```svg
<svg viewBox="0 0 560 300">…</svg>
```
*这张图回答：为什么 X 会导致 Y？*
````

图注那一行必须以 `*图：` 或 `*这张图回答：` 开头，紧跟在代码块后面（中间可以有空行）。

## 原样放进页面的 HTML

````
```html
<div class="cmp">…</div>
```
````

用于并排卡、实验台、动态图。其他语言的代码块（不写语言或写别的）会显示成等宽文字图，适合 ASCII 流程图。

## 折叠块

```
<details>
<summary>作者的问题答上了没</summary>
主问题：……答上了，见 1-2 节。
次要问题 1：……答了一半，差在……。
</details>
```

`<details>` 和 `</details>` 各占一行。块里每一行变成一段。

## 选择题

```
**Q1：为什么……？**
- A. ……
- B. ……
- C. ……
- D. ……

<details>
<summary>展开答案</summary>
答案：C。理由……
</details>
```

题号写 `Q1` 到 `Q7`，或「先猜再看」用的 `猜1`、`猜2`。选项点了当场判对错并展开答案，只认第一次。

## 表格和列表

- 表格：标准 `| a | b |` 写法。
- 列表：`- ` 或 `1. ` 开头。**不支持缩进的嵌套列表**，要分层就写成平的 1、1.1、1.2。

## 行内

`**粗体**`、`*斜体*`、`` `代码` ``、`[文字](https://链接)`。
